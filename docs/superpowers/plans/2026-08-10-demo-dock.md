# DemoDock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace three overlapping floating widgets with one demo-only, collapsible dock that switches brand colour mode, navigates the whole estate, and offers demo sign-in credentials.

**Architecture:** A shell (`DemoDock`) owns floating position, collapse and tabs, and knows nothing about content. Three panels supply content and know nothing about position: `AppSwitcherPanel` (extracted from `zone-switcher.tsx`), `ColorModeSwitcher` (existing, reused as-is), and `DemoAccountsPanel` (extracted from `DemoFab`). Because the dock mounts once in the hub root layout — above every page — demo accounts come from a pathname-keyed registry rather than props.

**Tech Stack:** React 19, TypeScript strict, Next.js 16 (hub), plain CSS on `--ds-*` tokens (no Tailwind in the design system), Storybook 8, `node --test` for design-system unit tests.

## Global Constraints

- **TypeScript strict, no `any`. Named exports only.** (CLAUDE.md)
- **Tokens, never raw values.** No hex, px, rgba or shadows in design-system CSS; use `--ds-*`. Enforced by `npx stylelint --config .stylelintrc.tokens.json "packages/design-system/components/**/*.css"`.
- **No Tailwind inside `packages/design-system/`.** Semantic classes only.
- **Material Symbols Rounded via `<Icon>`** for icons; no other icon set.
- **No AI attribution in commit messages.**
- **Never edit generated files:** `packages/tokens/dist/*`, `packages/design-system/tokens.css`, `apps/hub/public/storybook/*`.
- **Coverage gate must end at 69/69** with `apps/storybook/coverage-baseline.json` `missing: []`.
- **Work in an isolated git worktree.** A concurrent session is editing ~30 files on `main`; use `superpowers:using-git-worktrees` before Task 1 so verification runs are not polluted.

`findDemoAccounts` implementation:

```ts
export function findDemoAccounts(pathname: string): DemoAccountSet | null {
  let best: DemoAccountSet | null = null;
  for (const set of DEMO_ACCOUNTS) {
    if (pathname === set.path || pathname.startsWith(`${set.path}/`)) {
      if (!best || set.path.length > best.path.length) best = set;
    }
  }
  return best;
}
```
