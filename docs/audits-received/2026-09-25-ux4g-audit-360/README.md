## Reading it

The report states on its own pages that it is **generated through AI** and that
"AI can make mistakes". Treat the scores as a signal, not a finding: each low
parameter needs confirming by hand before it goes into a work plan. GIGW at 72%
is the weakest and is also the one with a legal obligation behind it.

Note the tension with the DBIM observations received two days earlier: this tool
scores accessibility at 83%, while a manual check of the same homepage found 86
of 96 images with empty alternative text and 81 unnamed controls. An automated
score is not a compliance statement.
