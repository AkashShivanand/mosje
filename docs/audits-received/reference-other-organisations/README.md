examples, kept so we can see what the auditors' own output looks like and how
they score.

Useful for one thing in particular: the UPSC Audit 360 covers **three pages**
(Home, About Us, Contact Us) where ours covers one. If a future run of the tool
on dosje.gov.in should cover more than the homepage, this is the precedent to cite.

Do not quote these scores as if they were ours.
