# @mosje/design-system

Shared UI **components** for the MoSJE digital estate, aligned to the **UX4G Figma DS**. Consumed by the website (`apps/dosje`, Tailwind v4) and the portals (`apps/portals/*`, Tailwind v3 via `@mosje/config`).

## Tokens live in `@mosje/tokens`

This package does **not** own tokens. The single source of truth is **`@mosje/tokens`** (DTCG JSON → Style Dictionary v4), which generates the `--ds-*`/`--sa-*` CSS contract into `packages/design-system/tokens.css` (and the Tailwind presets, TS, and a Figma DTCG export).

- **Edit tokens** in `packages/tokens/src/*.json` (primitive → semantic → component), then `npm run build -w @mosje/tokens`. `npm test -w @mosje/tokens` asserts the contract.
- **`tokens.css`** here is **generated — do not edit.** `tokens.ts` is a typed mirror for the named-export API (`colors`/`radius`/`typography`), reconciled with `@mosje/tokens`.
- **Figma sync** (no Code Connect): see `/sync-figma` and `docs/research/figma-code-connect-readiness.md`. Code→Figma via the DTCG export `packages/tokens/dist/figma.tokens.json`.

## Components

12 token-driven atoms (semantic CSS + `--ds-*`, portable across Tailwind majors): `Button`, `Card` (+ sub-parts), `Badge`, `Chip`, `Checkbox`, `Radio`, `Toggle`, `Search`, `Alert`, `Loader`, `EmptyState`, `Avatar`. Import from the root:

The full component inventory (navigation, forms, dashboard/charts, `UX4GAccessibilityWidget`, etc.) is much larger than this atom list — see [`design.md`](./design.md) for the authoritative, kept-in-sync inventory.

```tsx
import { Button, Card, Badge } from "@mosje/design-system";
```

Each atom ships its own CSS (auto-bundled). `components.css` is a barrel for non-bundled consumers. Component ↔ Figma node map (for future Code Connect): `docs/research/figma-code-connect-readiness.md`.

## Consuming
- **Website (Tailwind v4):** `apps/dosje/src/app/globals.css` imports `@mosje/design-system/tokens.css` and maps `--ds-*` → Tailwind theme; `next.config.ts` sets `transpilePackages` + `turbopack.root`; `tsconfig` sets `preserveSymlinks`.
- **Portals (Tailwind v3):** import `@mosje/config/tailwind-preset` (generated by `@mosje/tokens`) + `@mosje/design-system/tokens.css`.
