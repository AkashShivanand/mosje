---
description: Run a WCAG 2.1 AA + GIGW accessibility audit on a page or component.
argument-hint: "<path to page/component, e.g. dosje/src/components/Header.tsx>"
allowed-tools: Read, Grep, Glob, Bash, Agent
---

Audit **$ARGUMENTS** for accessibility.

1. If no path is given, ask which page/component (or default to the most recently edited UI file).
2. Dispatch the **accessibility-auditor** agent on the target file and the shared UI it depends on.
3. Return the FAIL → WARN → PASS report with concrete fixes and the final verdict (**AA COMPLIANT** or **NOT COMPLIANT (N blockers)**).
4. If there are FAIL items and the user asks, offer to apply the fixes — otherwise report only.

Remember: these are Government of India sites — accessibility failures are blockers, not suggestions.
