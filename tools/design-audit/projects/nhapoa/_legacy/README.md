# Legacy per-portal scripts

These ran the NHAPOA audit before `tools/design-audit/engine/` existed. They are kept for
provenance — they are the record of how that portal's published findings were produced — and are
NOT the way to run an audit now. Use the engine.

They were moved out of `docs/qc/portals/nhapoa/` on 2026-09-11, when the deliverable spec
was written down: that folder holds the published deliverable, not the machinery that made it.
